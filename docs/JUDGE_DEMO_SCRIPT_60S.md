# Judge Demo Script (60 seconds) — Shortfall Prevention

> Definition on screen the whole time: "Cash-flow shortfall = completed month
> where recorded expenses exceed recorded income."

**0–12s — Baseline (transaction-derived, honest).**
Open Dashboard → "Your shortfall prevention progress". Read aloud: "Past
shortfall rate X% over N completed months, average gap ৳Y. Current partial
month is excluded — thin history shows 'insufficient history', not a fake
rate." (Synthetic demo data is labelled synthetic.)

**12–25s — Forecasted risk.**
"Next 4 weeks: HIGH/MEDIUM risk, projected gap ৳Z, confidence medium/low.
Forecasted shortfall means projected 4-week expenses exceed income, or the
predicted balance goes negative when a reliable wallet balance exists."

**25–42s — One prioritized Bangla/Banglish plan.**
Open Forecast → Shortfall Prevention Plan (first card). "Top driver from
your own transactions: Food. One next step only: cut Food spending by 10%
this week. Advice only — this plan never moves money; savings transfers stay
separately confirmed by you." Toggle Auto/বাংলা/English.

**42–53s — Accept / dismiss / usefulness feedback.**
Click "Accept plan", then "Was this useful? → Useful", pick which part
helped (forecast / expense explanation / wording / action / none), tick the
consent box (required), Skip is always available.

**53–60s — How outcome is measured honestly.**
"Future completed months after acceptance are compared with pre-plan months
— observational before/after, never causal from advice alone. Aggregates
need 10+ users and 2+ months per arm, else we say 'Insufficient evidence
to estimate impact.' Interviews pending — no qualitative claims yet."
